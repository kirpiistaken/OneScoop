# 2.1 tasarımları

Kaynak: "OneScoop Rozet Taslakları" tasarım sayfası (Claude artifact
https://claude.ai/artifact/JZ8XSAik1ABAcwEVxWKpt8).

- **Badges-Medal.dc.html** — SEÇİLEN rozet tarzı: madalya + kurdele.
  - Kenar tırtıklı madalya, arkada kurdele uçları, ortada dolu/büyük ikon.
  - Bantta sadece sayı (7 · 30 · 100 · 365), beyaz, hafif bloom,
    seviyenin koyu tonunda ince kontur. Birim ("GÜN") yazılmıyor.
  - Seviye renkleri: bronz (7) · gümüş (30) · altın (100) · mavi (365).
  - Özel rozetler: İlk Scoop "1." · Yükleme Tamam "7" · Kutu Bitti "%100"
    (EN: "100%") · Kusursuz Ay "30/30". Kilitli: gri + "42/365" ilerleme.
- **Badges-Screen.dc.html** — Rozetler ekranı örneği.
- **Weekly.dc.html / Monthly.dc.html** — Haftalık/aylık rapor taslakları.

Kural: rozetler sadece o gün (ertesi sabah 04:00'e kadar) girilen
kayıtları sayar; takvimden geçmişe eklenen günler sayılmaz
(DoseEntry.takenAt ile ayırt edilir).
